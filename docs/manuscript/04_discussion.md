# Discussion

The outline governs the course navigation, while files on disk govern
which materials are attached to each session. A site can therefore
represent work in progress and still provide stable navigation for an
instructor reviewing it. An empty session is a meaningful output of
assembly and does not imply that lesson files were drafted.

This exercise checks the filesystem and HTML boundary of one retained
fixture. It cannot establish lesson quality, browser rendering of
externally loaded assets, or the quality of a model's drafts. The
repository's archived course outputs preserve earlier examples. The
fixture requires no change to those outputs or to the retained archive.
