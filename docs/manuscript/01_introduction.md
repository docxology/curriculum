# Introduction

Curriculum accepts YAML for course structure, model settings, and output
layout. An outline records course metadata and a hierarchy of modules and
sessions. The model-backed stages can draft JSON, prose, or diagrams.
Once those artifacts exist, the static builder can assemble and present
them independently of the model [@curriculumSource].

An outline can contain planned sessions before their materials are ready.
An author reviewing the generated website needs to distinguish a session
in the outline from files available for that session. The offline
experiment tests that distinction using an existing fixture rather than
the archived course outputs [@curriculumArchive].
