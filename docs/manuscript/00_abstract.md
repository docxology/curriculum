# Abstract

Curriculum is a Python toolkit for specifying a course and organizing its
materials by session. Drafting an outline and assembling a website are
separate operations. We test the assembly step using a checked-in JSON
outline, a lecture, and a diagram source. The site exposes the modules and
sessions named by the outline, and material buttons appear only for the
session with files. This fixture verifies the handoff from retained
sources to navigation and content without generating new lessons.
