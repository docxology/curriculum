# Reproducibility

The source checkout includes the sample outline, lecture, and diagram
under `tests/fixtures/`. Build the website in temporary storage using
the Stage 06 entry point. Use the author's configuration only to resolve
the course-specific input path. Read the generated markup and save the
button counts before rendering the manuscript figure. The
`fixture_receipt.json` data file records the measured counts and
material placement.

The pinned manuscript build invokes a separate renderer after completing
the local fixture checks. The browser-facing example and the manuscript
are different outputs. Stage 06 writes a course HTML file. Template
writes the technical PDF and manuscript website.
